# Olist E-Commerce Comprehensive Data Analytics and ML Pipeline

## Project Overview

This repository documents an enterprise-grade, end-to-end analytics pipeline engineered to translate raw Brazilian E-Commerce (Olist) telemetry into actionable business intelligence. Crucially, the architectural design and methodological approach were strictly governed by predefined business requirements. Rather than performing isolated statistical exercises, every data transformation, SQL aggregation, and Machine Learning inference was reverse-engineered from core stakeholder questions regarding customer loyalty, market saturation, logistics efficiency, and true customer sentiment.

While traditional quantitative metrics (e.g., 1-to-5 star ratings) offer a baseline heuristic for seller performance, they are highly susceptible to skew and frequently fail to capture nuanced qualitative experiences. To bridge this analytical gap, this project deploys advanced Natural Language Processing (NLP) to extract latent sentiment from unstructured review text, alongside K-Means clustering for Recency, Frequency, and Monetary (RFM) customer and seller segmentation. Fusing these qualitative insights with quantitative operational data drives strategic, data-driven decision-making.

## Repository Structure

* /Data Ingestion and ML.ipynb: The core Python ETL and Machine Learning engine. Automates the extraction of raw Olist CSV data, performs data cleaning and duplicate removal, executes K-Means clustering for RFM segmentation, runs BERT-based sentiment analysis on customer reviews, and loads the structured data into a SQL Server database via SQLAlchemy.
* /Analysis.sql: The Exploratory Data Analysis script. Contains advanced T-SQL queries used to validate data integrity, explore seasonal order trends, calculate average delivery and warehouse processing delays, and identify top-performing sellers and products.
* /Olist_ECommerce.pbix: The final Power BI dashboard. Translates the database into an interactive tool for stakeholders to analyze buyer demographics, seller metrics, RFM clusters, and AI-driven sentiment analysis.

## Architecture and Tech Stack

* Data Engineering (ETL): Python (Pandas, Numpy, SQLAlchemy)
* Machine Learning (Clustering): Scikit-Learn (K-Means, StandardScaler)
* Machine Learning (NLP): Hugging Face Transformers (AutoTokenizer, AutoModelForSequenceClassification), NLTK, SciPy
* Relational Database: Microsoft SQL Server (T-SQL)
* Data Visualization: Power BI

## Methodology and Project Phases

### Phase 1: Data Ingestion and Transformation (ETL & ML)
The Python pipeline systematically reads raw CSV datasets and transforms them for relational analysis. 
* Data Cleaning: Iteratively identifies and removes duplicates across all tables, handles missing values, and standardizes geolocation coordinates.
* Advanced Transformation (Clustering): Calculates Recency, Frequency, and Monetary metrics for buyers and sellers, scaling the data and applying a K-Means algorithm to generate optimized segments (e.g., Champions, Lost/Hibernating).
* Advanced Transformation (NLP): Integrates a pre-trained deep learning model to process the text of reviews (titles and messages), calculating probabilities and predicted stars based on qualitative feedback.
* Database Loading: Uses batch processing to securely push transformed records into a SQL Server database.

### Phase 2: Exploratory Data Analysis (SQL)
Before visualization, the data was rigorously tested and explored within SQL Server. Queries were designed to:
* Aggregate total revenue, top products, and peak shopping seasons (Year-Month).
* Analyze operational metrics, such as the average warehouse processing time in days partitioned by customer state.
* Cross-reference traditional star ratings against total volume sold and revenue generated by the top 50 sellers.

### Phase 3: Business Intelligence and Visualization
The Power BI dashboard serves as the final product, enabling stakeholders to interact with the data dynamically across two distinct audience perspectives.
